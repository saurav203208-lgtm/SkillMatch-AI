# SkillMatch AI

SkillMatch AI is a personalized career and skill development platform for students.

## Features

- User Registration and Login
- Student Profile Management
- Skill Assessment
- Career Recommendation
- Skill Gap Analysis
- Personalized Project Recommendations
- Learning Roadmap
- AI Assistant

## Technology Stack

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB
- JWT Authentication

## Project Structure

- `index.html` - Login and Sign Up
- `assessment.html` - Skill Assessment
- `dashboard.html` - Student Dashboard
- `chatbot.html` - AI Assistant
- `backend/` - Node.js and Express backend

## How It Works

1. Student creates an account or logs in.
2. Student completes the skill assessment.
3. Profile and assessment data are analyzed.
4. Career recommendations are generated.
5. Skill gaps are identified.
6. Projects and learning roadmap are recommended.
7. AI Assistant provides guidance.
